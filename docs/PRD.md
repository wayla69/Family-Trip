# PRD — Memory Bookshelf (ชั้นหนังสือความทรงจำของมีมี่และมีก้า)

สถานะ: **รออนุมัติจากเจ้าของ** · ที่มา: `docs/handoff/Memory_Bookshelf_Handoff.md` §2 + คำตอบเจ้าของ (17 ต.ค. 2026)

## ปัญหาและเป้าหมาย
แอปคู่มือทริป *The Harbour Hop* เก็บความทรงจำไว้ได้ทริปเดียว และผูกกับ Claude Artifact — แต่ความทรงจำของเด็กๆ ต้องอยู่ได้ 10–20 ปี
→ ทำ **ชั้นหนังสือ** บน Railway: แต่ละทริปคือหนึ่งเล่ม เล่มแรก ฮ่องกง–มาเก๊า (5–10 ธ.ค. 2026) เล่มสอง Australia (2–17 เม.ย. 2027)

## ผู้ใช้และสิทธิ์ (ตัดสินแล้ว)
| ใคร | เข้ายังไง | ทำอะไรได้ |
|---|---|---|
| ผู้ใหญ่ในครอบครัว | **รหัสครอบครัว** (`FAMILY_CODE`) + ชื่อเล่น | ทุกอย่าง: ลงรูป แก้ ลบ แต่งนิทาน import |
| ญาติ | **ลิงก์ลับดูอย่างเดียว** `/v/<VIEW_TOKEN>` | ดูชั้นหนังสือและเล่ม ดาวน์โหลด PDF |

ไม่มีระบบบัญชีรายคน/อีเมลใน MVP — แต่ฐานข้อมูลมี `family_id` และคอลัมน์ `role` เผื่อทำสิทธิ์ละเอียดภายหลัง

## User stories (MVP)
1. เห็นปกทุกทริปบนชั้น (gradient ปก ชื่อ วันที่ ตราประทับถ้าได้แล้ว) เปิดเล่มไหนก็ได้
2. เปิดเล่มเห็น: ปก · สถิติ 4 ช่อง (รูป/คำพูด/ครั้งแรก/ที่ไป) · ตราประทับ · ช่วงเวลาที่ชอบ ⭐ · ครั้งแรก · นิทานทั้งทริป · หน้าตามวัน (เฉพาะวันที่มีข้อมูล)
3. เพิ่ม/แก้ รูป · คำพูด (มีมี่/มีก้า/ทั้งคู่) · อารมณ์ 6 แบบต่อเด็กต่อวัน · ของโปรดวันนี้ · บันทึกพ่อแม่ · ครั้งแรก (รายการต่อทริป + เพิ่มเอง) · ⭐ ไฮไลต์ — ระหว่างทริปและย้อนหลัง
4. กดให้ Claude แต่งนิทาน (วัน/ทั้งทริป) จากข้อความเท่านั้น ไม่ส่งรูป เก็บไว้กับเล่ม แต่งใหม่/ลบได้
5. ดาวน์โหลดเล่มเป็น PDF พร้อมรูปและฟอนต์ KIRA UI (สร้างฝั่ง server) + คัดลอกเป็นข้อความ
6. ส่งลิงก์ดูอย่างเดียวให้ญาติ (เปลี่ยน `VIEW_TOKEN` = ยกเลิกลิงก์เก่าทันที)
7. Import จากแอป Harbour Hop (`moments` + `visits` + `days` + รูป) มี dry-run แสดงจำนวนก่อน/หลัง, import ซ้ำได้ไม่ซ้ำรายการ

## พฤติกรรมที่ต้องคง (จากแอปเดิม)
หนึ่งแถวต่อหนึ่งรายการ (mood/fav/note = upsert ตามวัน+เด็ก) · ข้อความที่พิมพ์ค้างไม่หายเมื่อซิงก์ · ลบต้องแตะ 2 ครั้ง (3 วินาที) · ตราประทับได้เมื่อทุกวันกด Done หรือเลยวันสุดท้าย · มือถือก่อน (320–375 px) โหมดสว่าง/มืด ไทย/อังกฤษ · ใช้ได้ตอนเน็ตไม่ดี (คิวอัปโหลด retry)

## หน้าตา (เจ้าของกำหนด)
แอปและ PDF ที่ส่งออกต้อง **คงความสวยงามและรูปแบบของเล่ม Trip Operations Manual** (HK–Macau และ Australia) — ธีมต่อเล่ม, ตัวหนังสือแบบนิตยสาร, การ์ดวันแบบ "01 · Day 1", แผง route, ไทม์ไลน์, กล่อง Local pick → รายละเอียดใน `docs/DESIGN.md` (มาแทนโทนสีสดของ `docs/handoff/design_tokens.json`; ใช้จาก handoff เฉพาะ token อารมณ์/สีเด็ก)

## เพิ่มหลัง go-live (เจ้าของขอ 18 ต.ค. 2026: "UI ไม่น่าตื่นเต้น + อยากมีพาสปอร์ตเด็ก")
8. **พาสปอร์ตความทรงจำ** ของมีมี่และมีก้า (`#/passport/<kid>`, แท็บ 🛂, ญาติเปิดดูได้)
   - ปกพาสปอร์ต และหน้าข้อมูล: ชื่อ, นักเดินทางตั้งแต่, จำนวนทริป, ตราประทับ, ครั้งแรก, ธงที่ไป
   - หน้าวีซ่าต่อทริป: ตราภาพวาดหนึ่งดวงต่อวัน ได้ตราเมื่อวันนั้นมีบันทึกหรือกด Done; ตราใหม่มีแอนิเมชันปั๊มครั้งแรกครั้งเดียว
   - เหรียญ "ครั้งแรก" ของเด็กคนนั้น และคำพูดของหนู
   - คำนวณจากข้อมูลที่มีอยู่ ไม่มีตารางใหม่ และ **ไม่มีเลขพาสปอร์ตจริงหรือข้อมูลเอกสารใดๆ** (แถบ MRZ เป็นลายตกแต่งจากชื่อเล่นเท่านั้น)
10. **พาสปอร์ตนักผจญภัย** (เจ้าของขอ 18 ต.ค. 2026 ตามเล่ม *Kids Adventure Passport* ที่พิมพ์ไว้) ต่อเด็ก ต่อทริป
    - ปก "Adventure Passport · Explorer"
    - **Explorer ID**: สัตว์ที่ชอบ พลังพิเศษ ส่วนสูงวันแรก/วันสุดท้าย (พ่อแม่พิมพ์ให้)
    - ไกด์สองตัว: HK = Pinky + Bao · AU = Ranger Roo + Kiki
    - วีซ่า/ตราประทับ และ "เรานอนที่ไหนบ้าง"
    - ภารกิจรายวัน: ไกด์เล่าเกร็ดความรู้ · "วันนี้รู้สึก…" (ใช้อารมณ์เดียวกับหน้าบันทึก) · ติ๊กสิ่งที่เจอ 4 อย่าง
    - เช็กลิสต์: สัตว์ · อาหาร (อร่อย/ไม่ชอบ) · Master Explorer พร้อมใบประกาศเมื่อครบเป้า
    - หน้าระบายสี วาดรูป ติดสติกเกอร์ ยังอยู่ในเล่มกระดาษ ไม่ได้ทำในแอป
    - เก็บเป็น entries ชนิด `tick` / `field` (migration 0003) · เนื้อหาอยู่ใน seed `passport`
11. **แผนการเดินทางในเล่ม (Itinerary)**
    - แสดงทุกวันตามแผน: ที่ไป ที่นอน มื้ออาหาร
    - วันที่บันทึกแล้วมี ✓ และลิงก์ไปหน้าวันนั้น
    - หน้าวันแบบเต็มยังแสดงเฉพาะวันที่มีบันทึก
9. **ชั้นหนังสือมีชีวิตขึ้น**
   - การ์ด "การผจญภัยครั้งต่อไป": นับถอยหลังกี่วัน และระหว่างทริปบอกวันที่ X/Y พร้อมปุ่มบันทึกวันนี้
   - ปกเล่มโชว์รูปโปรด (แบบโพลารอยด์) หรือภาพวาดประจำวัน
   - แถบความคืบหน้าตราประทับ, เส้นทางภาพวาดในเล่ม, ภาพวาดประจำวันบนหัวหน้าวัน
   - ประกายเมื่อติ๊กครั้งแรก/อารมณ์/เช็คอิน/จบวัน
   - เคารพ `prefers-reduced-motion`

## ไม่ใช่ MVP
ไทม์ไลน์ข้ามทริป · สถิติสะสม · "วันนี้เมื่อปีก่อน" · ส่วนสูง/อายุต่อทริป · ภาพวาดเด็ก · เสียงอัด · บัญชีรายคน/สิทธิ์ 4 ระดับ

## ความเป็นส่วนตัว (PDPA)
ไม่มี public URL ของรูป (ส่งผ่าน backend ที่เช็กสิทธิ์) · ลบ EXIF/GPS ทุกรูป · `noindex` · ไม่ส่งรูปให้ AI · ส่งออกข้อมูลทั้งหมดและลบจริงได้ตามคำขอผู้ปกครอง · ไม่มีเลขจอง/พาสปอร์ตในระบบ · backup + ทดสอบกู้คืนก่อน go-live

## เกณฑ์ตรวจรับ
`docs/handoff/ACCEPTANCE.md` (หมวด A–G) — เขียนเทสต์ใหม่ยิง API/DB จริง โดยคงเจตนาของ `reference_tests/memtest.py`

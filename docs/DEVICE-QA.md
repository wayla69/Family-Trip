# ทดสอบบนมือถือจริง (HANDOFF Task 4)

ทำบน **iPhone (Safari)** และ **Android (Chrome)** อย่างละรอบ ใช้ URL production `https://<โดเมน>` · ติ๊ก ✅/❌ แล้วส่งผลกลับ (ถ้า ❌ แนบภาพหน้าจอ + รุ่นมือถือ/เวอร์ชัน iOS หรือ Android)

| # | ขั้นตอน | ผลที่ควรได้ | iPhone | Android |
|---|---|---|---|---|
| 1 | เปิดลิงก์ ใส่รหัสครอบครัว + ชื่อเล่น | เข้าชั้นหนังสือ เห็น 2 ทริป | | |
| 2 | ติดตั้ง: iPhone → ปุ่มแชร์ → *Add to Home Screen* · Android → ⋮ → *Install app* | มีไอคอนสมุดบนหน้าจอ เปิดแล้วไม่มีแถบ URL และยังล็อกอินอยู่ | | |
| 3 | ปุ่ม 📷 → ถ่ายรูปด้วยกล้อง | รูปขึ้นในตัวอย่าง หมุนถูกด้าน | | |
| 4 | ปุ่ม 📷 → เลือกรูปจากคลัง **5 รูปขึ้นไป** (iPhone: ให้มีรูป HEIC/Live Photo ปนด้วย) → บันทึก | รูปครบทุกใบ หมุนถูกด้าน ไม่มีรูปแตก/ดำ | | |
| 5 | เปิด **โหมดเครื่องบิน** → บันทึกรูป 1 ใบ + ข้อความ "ทดสอบออฟไลน์" | ขึ้นในเล่มพร้อมป้าย ⏳ | | |
| 6 | ปิดโหมดเครื่องบิน แล้วรอ ~30 วินาที (หรือปิดเปิดแอป) | ป้าย ⏳ หายไป · ความทรงจำนั้นมี **อันเดียว** ไม่ซ้ำ · มือถืออีกเครื่องเห็นด้วย | | |
| 7 | ตั้งมือถือเป็น **โหมดมืด** | สีอ่านง่าย ไม่มีตัวหนังสือจม | | |
| 8 | ขยายขนาดตัวอักษรของระบบให้ใหญ่ขึ้น | ไม่มีข้อความล้นจอ/เลื่อนซ้ายขวาได้ | | |
| 9 | กดสลับภาษา TH ↔ EN | ข้อความเปลี่ยนทั้งหน้า | | |
| 10 | แตะรูป → ปัดซ้าย/ขวาในหน้าดูรูป | เลื่อนรูปได้ ปิดได้ | | |
| 11 | เปิด `#/book/harbourhop2026/mimi` → พิมพ์ / PDF | หน้า A5 เรียงถูก ไม่มีหน้าว่างแทรก | | |
| 12 | เปิดลิงก์ญาติ `https://<โดเมน>/v/<VIEW_TOKEN>` ในเบราว์เซอร์อื่น | ดูได้ แต่ไม่มีปุ่ม 📷 และแก้ไขอะไรไม่ได้ | | |

**ข้อควรรู้**
- ถ้ารูป HEIC ไม่ขึ้นบน iPhone: Settings → Camera → Formats → *Most Compatible* เป็นทางแก้ชั่วคราว แล้วแจ้งกลับ
- อัปโหลดรูปเต็มหลายใบผ่าน 4G อาจใช้เวลา — ถ้าค้างนานเกิน 2 นาทีให้จดไว้
- หลังมีการอัปเดตแอป: ปิดแอปแล้วเปิดใหม่ 1–2 ครั้งเพื่อให้ได้เวอร์ชันใหม่ (service worker)

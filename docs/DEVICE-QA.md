# ทดสอบบนมือถือจริง

ทำบน **iPhone (Safari)** และ **Android (Chrome)** อย่างละรอบ ใช้ URL production `https://<โดเมน>` · ติ๊ก ✅/❌ แล้วส่งผลกลับ (ถ้า ❌ แนบภาพหน้าจอ + รุ่นมือถือ/เวอร์ชัน iOS หรือ Android)

| # | ขั้นตอน | ผลที่ควรได้ | iPhone | Android |
|---|---|---|---|---|
| 1 | เปิดลิงก์ ใส่รหัสครอบครัว + ชื่อเล่น | ชั้นหนังสือ 2 เล่ม (ฮ่องกง–มาเก๊า สีกรมท่า · Australia สีเขียว) | | |
| 2 | ติดตั้ง: iPhone → ปุ่มแชร์ → *Add to Home Screen* · Android → ⋮ → *Install app* | มีไอคอนบนหน้าจอ เปิดแล้วไม่มีแถบ URL และยังล็อกอินอยู่ | | |
| 3 | เปิดเล่มฮ่องกง → แท็บ ✏️ บันทึก → **＋ เพิ่มรูป** → ถ่ายรูปด้วยกล้อง | รูปขึ้น หมุนถูกด้าน มีตัวนับ "กำลังอัปโหลด 1/1" | | |
| 4 | **＋ เพิ่มรูป** → เลือกจากคลัง **5 รูปขึ้นไป** (iPhone: ให้มีรูป HEIC/Live Photo ปน) | รูปครบทุกใบ หมุนถูกด้าน ไม่มีรูปแตก/ดำ · ตัวนับ i/n เดินจนหาย | | |
| 5 | พิมพ์คำพูดในช่อง แล้วสลับผู้พูด มีมี่ ↔ มีก้า ก่อนกดบันทึก | ข้อความที่พิมพ์ไว้ไม่หาย | | |
| 6 | เปิด **โหมดเครื่องบิน** → บันทึกคำพูด 1 อัน + รูป 1 ใบ | ขึ้นทันที คำพูดมีป้าย ⏳ · มีข้อความ "ออฟไลน์" ด้านบน | | |
| 7 | ปิดโหมดเครื่องบิน แล้วรอ ~30 วินาที (หรือปิดเปิดแอป) | ป้าย ⏳ หาย · คำพูด/รูปนั้นมี **อันเดียว** ไม่ซ้ำ · มือถืออีกเครื่องเห็นด้วย | | |
| 8 | แตะอีโมจิอารมณ์ แล้วแตะอันเดิมซ้ำ | แตะแรกเลือก แตะซ้ำล้าง | | |
| 9 | แตะรูป → ปัดซ้าย/ขวา → ใส่คำอธิบาย → ⭐ → ลบ (แตะ 2 ครั้ง) | ตัวนับ "2 / 5" เปลี่ยนตาม · แตะลบครั้งแรกแค่เตือน ครั้งที่สองลบ | | |
| 10 | แท็บ 📖 สมุด | ปก + สถิติ 4 ช่อง + ตราประทับเส้นประ + ช่วงเวลาที่ชอบ ⭐ + หน้าวัน "02" แบบเล่มคู่มือ | | |
| 11 | ตั้งมือถือเป็น **โหมดมืด** | สีอ่านง่าย ไม่มีตัวหนังสือจม | | |
| 12 | ขยายขนาดตัวอักษรของระบบให้ใหญ่ขึ้น | ไม่มีข้อความล้นจอ/เลื่อนซ้ายขวาได้ | | |
| 13 | กดสลับภาษา ไทย ↔ EN (มุมขวาบน) | ข้อความเปลี่ยนทั้งหน้า | | |
| 14 | ในสมุด → **พิมพ์ / PDF** | หน้า A4 วันละหน้า รูปไม่ฉีกกลางหน้า | | |
| 15 | เปิดลิงก์ญาติ `https://<โดเมน>/v/<VIEW_TOKEN>` ในเบราว์เซอร์อื่น | ดูสมุดและรูปได้ แต่ไม่มีแท็บ ✏️ บันทึก ไม่มีปุ่มลบ | | |

**ข้อควรรู้**
- รูปถูกย่อในมือถือก่อนส่ง (ประหยัดเน็ต) และเซิร์ฟเวอร์ลบตำแหน่ง GPS ออกทุกใบ
- ถ้ารูป HEIC ไม่ขึ้นบน iPhone: Settings → Camera → Formats → *Most Compatible* เป็นทางแก้ชั่วคราว แล้วแจ้งกลับ
- หลังมีการอัปเดตแอป: ปิดแอปแล้วเปิดใหม่ 1–2 ครั้งเพื่อให้ได้เวอร์ชันใหม่

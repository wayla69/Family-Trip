# เกณฑ์ตรวจรับ — Memory Bookshelf MVP

ที่มา: ชุดทดสอบของแท็บความทรงจำในแอป Harbour Hop (83 ข้อ, ผ่านทั้งหมดกับ mock) — `reference_tests/memtest.py` ใช้ Playwright; ในระบบใหม่ให้เขียนใหม่ให้ยิง API จริง/test DB แต่คงเจตนาของแต่ละข้อไว้

## A. ชั้นหนังสือและเล่ม
- [ ] หน้าแรกแสดงปกทุกทริปเป็นเล่ม (ปก = gradient `cover`, ชื่อทริป, วันที่, ตราประทับถ้าได้แล้ว)
- [ ] เปิดเล่มฮ่องกง–มาเก๊าแล้วเห็น: ปก, สถิติ 4 ช่อง (รูป/คำพูด/ครั้งแรก/ที่ไป), ตราประทับ, ช่วงเวลาที่ชอบ (⭐), ครั้งแรก, นิทานทั้งทริป, หน้าตามวัน
- [ ] เฉพาะวันที่มีข้อมูลเท่านั้นที่ขึ้นเป็นหน้าในเล่ม
- [ ] ตราประทับเป็นเส้นประจนกว่าทุกวันกด Done หรือเลยวันสุดท้ายของทริป

## B. บันทึกรายวัน
- [ ] แถบ 6 วัน (กดสลับได้) แสดงจำนวนรายการ/ป้าย "วันนี้"
- [ ] คำพูด: เลือกผู้พูด (มีมี่/มีก้า/ทั้งคู่) + ข้อความ; ข้อความที่พิมพ์ค้างไม่หายเมื่อสลับผู้พูดหรือมีข้อมูลซิงก์เข้า
- [ ] อารมณ์ 6 แบบต่อเด็กหนึ่งคนต่อวัน; แตะซ้ำ = ล้างค่า
- [ ] ของโปรดวันนี้ + บันทึกพ่อแม่ (บันทึกเมื่อออกจากช่อง; ว่าง = ลบ)
- [ ] ครั้งแรก: แตะรูปเด็กเพื่อติ๊ก/ยกเลิก; เพิ่มข้อกำหนดเองได้
- [ ] ทุกอย่างข้างบนมีไฟล์เดียวต่อรายการ (ไม่มีเอกสารรวมต่อวันที่สองคนเขียนทับกัน)
- [ ] การลบทุกชนิดต้องแตะสองครั้ง (ครั้งแรกขึ้นข้อความยืนยัน หมดเวลา 3 วินาที)

## C. รูป
- [ ] เลือกหลายรูปพร้อมกัน; ย่อเป็น JPEG ด้านยาว ≤ 1600 px, orientation ถูกต้อง, **ไม่มี EXIF/GPS**
- [ ] แสดงความคืบหน้า "กำลังอัปโหลด i/n"; รูปที่ล้มเหลวไม่ทำให้รูปอื่นหาย; มีข้อความเมื่อพื้นที่เต็ม/ถูกจำกัดความถี่
- [ ] แตะรูป → ตัวดูเต็มจอ: คำอธิบาย, ⭐, ลบ (แตะสองครั้ง), ก่อนหน้า/ถัดไป + ตัวนับ "2 / 3"
- [ ] ผู้ใช้สิทธิ์ต่ำกว่า Editor ไม่เห็นปุ่มลงรูป/ลบรูป และเห็นข้อความอธิบาย
- [ ] ไม่มีทาง "เดา URL" เพื่อดูรูปของคนอื่นหรือของครอบครัวอื่น (ทดสอบ IDOR)

## D. นิทาน
- [ ] ปุ่มแต่งนิทานของวัน/ทั้งทริป — เรียก AI เมื่อกดเท่านั้น, แสดงข้อความสตรีมระหว่างรอ, มีปุ่มหยุด
- [ ] พรอมต์ส่งเฉพาะข้อความ (ไม่มีรูป) และมีกติกาห้ามแต่งเหตุการณ์ (ดู Handoff §6); วันที่ไม่มีข้อมูลเลยให้ขึ้นข้อความแทนการเรียก
- [ ] บันทึกนิทานไว้กับเล่ม, แต่งใหม่/ลบได้; ล้าง markdown ก่อนบันทึก

## E. ส่งออก
- [ ] ดาวน์โหลดสมุดเป็น PDF พร้อมรูปและฟอนต์ KIRA UI; หน้าหนึ่งวันไม่ฉีกกลางรูป
- [ ] คัดลอกเป็นข้อความได้ (วัน, ที่ไป, อารมณ์, คำพูด, ของโปรด, บันทึก, ครั้งแรก)

## F. Import จากแอป Harbour Hop
- [ ] importer มี dry-run แสดงจำนวนตามประเภท; จำนวนหลัง import = ก่อน import (รูป/คำพูด/ครั้งแรก/ที่ไป)
- [ ] import ซ้ำได้โดยไม่ซ้ำรายการ (idempotent ใช้ id เดิมเป็น external_id)
- [ ] ค่าที่ผิดรูปแบบ (ไม่ผ่าน moments.schema.json) ถูกรายงานเป็นรายการ ไม่ทำให้ทั้งชุดล้ม
- [ ] รูปทุกใบผ่านการลบ EXIF และไปอยู่ใน storage ใหม่ (ไม่อ้าง asset id เดิม)

## G. ไม่ใช่ฟังก์ชัน
- [ ] ใช้งานได้ที่ 320 และ 375 px ไม่มี horizontal scroll; โหมดสว่าง/มืด; ภาษาไทย/อังกฤษ
- [ ] ตรวจบนจอ PC กว้างด้วย preview_eval: ตัวอักษรและรูปไม่เล็กหรือยืดเกินไป (grid แบบ auto-fill)
- [ ] ใช้งานตอนเน็ตช้า: อัปโหลดมี retry/queue; ข้อความที่พิมพ์ไม่หาย
- [ ] สำรอง DB + storage และทดสอบกู้คืนหนึ่งครั้งก่อน go-live
- [ ] smoke test หลัง deploy; UAT บนมือถือจริงกับเจ้าของ (iPhone/Android) ด้วยรูปจริง
- [ ] CI เขียวทุก check ก่อน merge; migration journaled; ไม่มี secret ใน repo
- [ ] ลบข้อมูลของเด็กตามคำขอได้ (PDPA): ลบรายการ ลบรูปจาก storage จริง และส่งออกข้อมูลทั้งหมดได้

# วิธีใช้ไฟล์คำสั่งกับ Claude แชต

> **สถานะ (23 พ.ย. 2026):** batch-01 ถึง 05 รวมผลเข้าคลังไปแล้วบางส่วน (ดูประวัติ commit และ `docs/library-proof/`) ที่เหลือยังไม่ได้ทำ
> ถ้าทำใน Claude Code บนเครื่องที่เชื่อม Claude in Chrome แล้ว ใช้ `HEAD.md` เป็นเกณฑ์ และตรวจทุกร้านใน Google Maps (สถานะและรีวิวล่าสุด) ก่อนใส่ `ok`

1. เปิดแชตใหม่ใน claude.ai แล้วเปิด **Research** (หรือ web search)
2. เปิดไฟล์ `batch-01.md` คัดลอกทั้งไฟล์ วางในแชต แล้วส่ง (ไฟล์ละ 4 เมือง)
3. Claude จะตอบเป็น JSON เมืองละหนึ่งก้อน คัดลอกคำตอบทั้งหมดส่งกลับมาที่นี่ หรือบันทึกเป็นไฟล์ `.txt` แล้วแนบมา
4. ผมจะรันตัวตรวจ (เปิดลิงก์ทุกแถว หาชื่อ ประโยค และวันที่) แล้วคัดแถวที่ไม่ผ่านทิ้ง เขียนภาษาไทย และรวมเข้าคลัง
5. ทำ batch ถัดไป จะส่งมาทีละ batch หรือหลาย batch พร้อมกันก็ได้

**ข้อแนะนำ**
- 1 แชตต่อ 1 batch คำตอบจะไม่ยาวจนถูกตัด
- ถ้าคำตอบถูกตัดกลางคัน ให้พิมพ์ "continue" แล้วส่งส่วนที่เหลือมาด้วย
- `INDEX.txt` บอกว่าแต่ละ batch มีเมืองอะไร (ทั้งหมด 32 batch, 126 เมือง)
- batch-01 ถึง 06 เป็นเมืองในเอเชีย ออสเตรเลีย และนิวซีแลนด์ ที่ครอบครัวไทยไปบ่อยที่สุด ควรทำก่อน

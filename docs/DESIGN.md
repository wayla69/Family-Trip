# Design — Memory Bookshelf ใช้ภาษาภาพเดียวกับ Trip Operations Manual

ที่มา: เล่ม PDF ของเจ้าของ *Hong Kong & Macau with the kids — Trip Operations Manual* (issued 3 Oct 2026, 26 หน้า) และ *Australia Family Road Trip — Trip Operations Manual* (revised 3 Oct 2026, 36 หน้า)
หลักการ: **แอปต้องดูเหมือนหนังสือเล่มนั้นที่มีชีวิต** — กระดาษขาว ตัวหนังสือแบบนิตยสาร เส้นบางคั่น สีประจำทริปสีเดียว ไม่ใช่แอปการ์ดสีสด
(PDF ไม่ commit ลง repo — มีข้อมูลการจอง)

## 2. ตัวอักษร
- เนื้อหา/UI: **KIRA UI** 400/500/600/700 (ไทย+ละติน) — ตามกฎเจ้าของ
- Display: ตามธีมเล่ม (`--display-font`) · HK ใช้ Cormorant Garamond (OFL, self-host woff2 ใน `public/fonts/`, ไม่โหลดจาก Google) ไทยในหัวข้อ fallback เป็น KIRA UI
- ชื่อจีน (ป้าย "Show the driver"): Noto Sans HK / PingFang HK fallback
- สเกล (มือถือ → จอกว้าง ใช้ `clamp`): kicker 11px ตัวพิมพ์ใหญ่ letter-spacing .12em · label 12px · body 15–16px · หัวข้อวัน 24–30px · ชื่อเล่ม 40–64px · เลขวัน 34–48px

## 4. Layout
- มือถือ 320–390px: คอลัมน์เดียว, แผง route อยู่บนไทม์ไลน์, ระยะขอบ 16px, ไม่มี horizontal scroll
- จอกว้าง ≥ 900px: เหมือนหน้า A4 — แผง route ซ้าย 200–240px + ไทม์ไลน์ขวา, ความกว้างเนื้อหาสูงสุด ~960px, grid แบบ auto-fill
- PDF ส่งออก: A4 แนวตั้ง (ตรงกับเล่มคู่มือ) หนึ่งวันเริ่มหน้าใหม่ `break-inside: avoid` ที่รูปและกล่อง
- โหมดมืด: พื้น `#12161C`, panel `#1B2129`, accent สว่างขึ้น (HK `#8FB0E0`, AU `#7FBF9F`), กล่อง callout เป็นสีเข้มโปร่ง 18%

## 5. ความสนุก (เพิ่ม 18 ต.ค. 2026): ยังเป็นเล่มคู่มือ แต่มีชีวิต
- **ภาพวาดประจำวัน**: วงกลมเส้นหนา `#22213A` 2.4px; ที่อยู่ไฟล์ = `theme.art` ใน seed
  - HK: `/art/hk/day-{n}.svg` (วาดใหม่ 6 ภาพ)
  - AU: `/art/day-{n}.svg` (16 ภาพ)
  - ทริปที่สร้างในแอปใช้ emoji ของวันแทน
  - ใช้ที่: เส้นทางในเล่ม, หัวหน้าวัน, ตราพาสปอร์ต, ปกบนชั้น, หน้า login
- **ธง**: `theme.places[{flag, th, en}]`
- **ตัวละครมีมี่และมีก้า**: `public/art/kids/{mimi,mika}.svg` (หน้าในวงกลม) + `-full.svg` (ทั้งตัว มีมี่ลากรถเข็นกล่อง)
  - วาดสไตล์เดียวกับภาพประจำวัน จากรูปที่เจ้าของส่งมา
  - ตัวรูปถ่ายไม่ได้อยู่ใน repo
  - ใช้แทน emoji เด็ก: badge, pill อารมณ์, chip, ปก/หน้ารูปพาสปอร์ต, การ์ด hero, หน้า login, เล่มว่าง
- **การ์ด hero**: พื้น gradient จาก `--accent` + แสงจาก `--accent2` (เป็นที่เดียวที่ใช้ gradient) ตัวเลขใหญ่ display font
- **พาสปอร์ต**
  - ปกสีเข้มต่อเด็ก (มีมี่ `#8E2453`, มีก้า `#1F4E8C`) ตัวอักษรทอง `#E9C46A`
  - หน้ากระดาษลายเส้นวงกลมจางๆ (guilloche)
  - ตรายังไม่ได้ = เทา + ขอบประ; ได้แล้ว = สีเต็ม เอียงสุ่มคงที่ + ขอบสี `--accent2`
  - เหรียญครั้งแรก = วงทอง
- **Motion**
  - เข้าหน้าใหม่: fade-up 0.38s (ไม่เล่นตอนบันทึก)
  - ภาพวาดลอยเบาๆ, ตราใหม่ "ปั๊ม", ประกาย emoji 0.7s
  - ปิดทั้งหมดเมื่อ `prefers-reduced-motion` และตอนพิมพ์

## 6. สิ่งที่ไม่ใช้
gradient สีสดทั้งหน้า, การ์ดเงาหนา, emoji เป็นหัวข้อหลัก — emoji ใช้เฉพาะในจุดเล็ก (อารมณ์, ครั้งแรก) ตามเล่มคู่มือ

## 7. สีสดขึ้น (เจ้าของ 18 ต.ค. 2026: "ปรับสีสันทุกหน้าให้ดูสดใส เน้นส่วนที่ต้องเน้น")
ยังเป็นหน้าแบบรายงานตามคู่มือ แต่แต่ละหมวดมีสีของตัวเอง (`--tc`) และสิ่งสำคัญที่สุดต้องเด่นที่สุดในหน้า
- สีเน้น (app.css `:root`): `--hot` แดง (ฉุกเฉิน, ป้าย ★ ร้านแนะนำ) · `--sun` เหลือง (Local pick, ครั้งแรก, บันทึก) · `--sky` ฟ้า (แผน, กล่องข้อมูล) · `--leaf` เขียว (เตรียมตัว, เงินวันนี้, ราคา) · `--grape` ม่วง (สมุด) · `--rose` ชมพู (หัวใจ) · `--tealc` เขียวน้ำทะเล (เรียนรู้) · `--slate` เทา (ออฟไลน์) · มีค่าโหมดมืดแยก
- ไทล์เมนู: พื้นสีอ่อนของหมวด + ขอบบน 4px + emoji บนวงกลมสี · หน้าหมวด (`.tp-<k>`): หัวข้อใหญ่ขีดเส้นใต้สีหมวด, หัวข้อส่วนมีแถบสีซ้าย 5px
- กล่องข้อความทุกชนิดมีเส้นซ้าย 4px สีของชนิด (pick = เหลือง, warn = แดง, info = ฟ้า, calm = เขียว) · "เงินวันนี้" เป็นแถบเขียว
- บัตรฉุกเฉิน (หน้า SOS): กรอบเส้นประแดง เบอร์หลักตัวใหญ่สีแดง ที่อยู่ทุกคืน (คืนนี้ไฮไลต์) บรรทัดเด็กหลงตัวหนาสีแดง

## 8. สรุปก่อน รายงานอยู่ข้างใน (เจ้าของ 18 ต.ค. 2026: "ดูเยอะๆ แล้วอ่านเยอะมาก… อยากดูเป็นรายงานให้กดเข้าไป")
หน้าหมวด (วันนี้ · แผนทั้งทริป · ที่พัก · ฉุกเฉิน · เตรียมตัว · เรียนรู้) เปิดมาเป็น **หน้าสรุป** ก่อนเสมอ ส่วนหน้ารายงานเต็มตามคู่มืออยู่ที่ `#/t/<trip>/<หมวด>/full`
- หน้าสรุป = การ์ดคำตอบใหญ่ (`.glc`) การ์ดละหนึ่งเรื่อง หัวข้อ + บรรทัดสั้น 1–2 บรรทัด (`brief()` ตัดที่ " — " / " · " / ". ") แตะการ์ดแล้วเปิดรายงานที่ส่วนนั้น (`/full/<k>` เปิดเฉพาะส่วน k และเลื่อนไปหา)
- ปุ่ม "📄 อ่านแบบรายงานเต็ม" (`.reportbtn`) อยู่ท้ายหน้าสรุปทุกหน้า หน้ารายงานมีปุ่ม "‹ กลับไปหน้าสรุป"
- วันนี้: ไทม์ไลน์ย่อ + การ์ด (เดินทาง · คืนนี้ · Local pick · ร้านแนะนำ · Plan B · เงินวันนี้ = ยอดรวมของวัน · อากาศ · เรียนรู้) → `/today/<i>/full` คือแผนเต็ม
- แผนทั้งทริป: วันละหนึ่งบรรทัด (รูป · วันที่ · ชื่อวัน · ที่นอน) แตะแล้วไปหน้าวันนี้ของวันนั้น
- ที่พัก: แถบคืนต่อคืน + ที่พักละหนึ่งบรรทัด ปุ่ม 📍 แผนที่ / 🚕 ให้คนขับดู · ฉุกเฉิน: ปุ่มโทรใหญ่ (เบอร์หลักแดงเต็ม) + ที่พักคืนนี้ + บรรทัดเด็กหลง
- ส่วนใหม่ใน `infoBlocks` ต้องส่งบรรทัดสรุป (`pg(k, sub, key, title, inner)`) ด้วย

## 9. เรียบ มืออาชีพ ไม่ใช่ "AI format" (เจ้าของ 18 ต.ค. 2026) — ใช้แทนส่วนที่ขัดกันใน §7
- โหมดพ่อแม่ไม่ใช้ emoji เป็นไอคอน ใช้ชุดไอคอนเส้นชุดเดียว `ic(name)` (core.js `ICONS`, SVG ในโค้ด ไม่โหลดจากภายนอก) · emoji ยังใช้ในโหมดเด็ก พาสปอร์ต และเนื้อหา (สัตว์ อารมณ์)
- หัวข้อส่วนไม่มี emoji นำหน้า (`noEmo()` ตัดออกจากชื่อส่วนใน `infoBlocks`)
- สี: สีประจำเล่มสีเดียว (`--accent`) + เทา · แดง (`--hot`) ใช้กับฉุกเฉิน/แผนสำรองเท่านั้น · เหลือง (`--sun`) ใช้กับ "วันนี้/คืนนี้" เท่านั้น · ไม่มีสีต่อหมวดแล้ว
- เลย์เอาต์: รายการเส้นบาง (hairline) แทนการ์ดสีเรียงกัน · ไม่มีแถบสีซ้าย ไม่มีกรอบเส้นประ · มุมโค้งค่าเดียว `--r` 12px
- หน้าวันนี้ = ใบงานของวัน: ไทม์ไลน์ + ตาราง ป้าย | คำตอบ (`.dsheet`) · ปุ่มหลักปุ่มเดียว (บันทึกวันนี้) ที่เหลือเป็นลิงก์ (`.qlink`)
- ตัวอักษร 4 ระดับ (`--fs-1..4`) · ป้ายหมวดตัวเล็กตัวพิมพ์ใหญ่ห่าง · ตัวเลขความกว้างเท่ากัน
- ป้ายภาษาไทยเมื่ออ่านภาษาไทย: ร้านเด็ด · แผนสำรอง · เงินวันนี้ (อังกฤษยังเป็น Local pick / Plan B)

## 10. อ่านง่าย เป็นข้อ มีสี เป็นสัดส่วน (เจ้าของ 18 ต.ค. 2026) — ต่อจาก §9
- ข้อความยาวจากคู่มือไม่แสดงเป็นก้อน: `points()` ตัดเป็นข้อ (". " "; " " · " ระดับบนสุด ไม่ตัดในวงเล็บ; ชิ้นที่ยังยาวตัดที่ " — " / ": "; จุดนับเฉพาะหลังอักษรละติน/ตัวเลข/วงเล็บ วันที่ไทยอย่าง มี.ค. ไม่ถูกตัด) · `pts()` = รายการข้อ · `lead()` = ข้อแรกเป็นบรรทัดหลัก ที่เหลือเป็นบรรทัดย่อยสีเทา · วงเล็บยาวลงเป็นบรรทัดเล็ก
- เงินวันนี้ = บิลเล็ก (รายการ | ยอดชิดขวา, ยอดรวมตัวหนาท้ายสุด) · ไทม์ไลน์ = บรรทัดหลัก + บรรทัดย่อย
- ทุกส่วนอยู่ในกล่องสี (`.cbox c-*`, หัวกล่องสีพร้อมไอคอน): ไทม์ไลน์ฟ้า · เดินทาง/ที่พักคราม · มื้ออาหารเหลือง (ป้ายมื้อสีตามมื้อ) · แผนสำรองแดง · เงิน/อากาศเขียว · ควรรู้เหลือง
- หัวข้อในหน้ารายงานเป็นกล่องสีผลัดกัน (ฟ้า เขียว เหลือง คราม ชมพู เขียวน้ำทะเล; ฉุกเฉินเริ่มด้วยแดง) และหน้าสรุปมีจุดสีตรงกัน — สีช่วยแบ่งส่วน ไม่ใช่สีต่อหมวดแบบเดิม

## 11. ร้านอาหาร: ทีละวัน ทีละมื้อ แล้วค่อยหน้ารวม (เจ้าของ 18 ต.ค. 2026)
- `#/t/<trip>/eat` เปิดมาที่วันนี้ (หรือวันแรก): แถบเลือกวัน → กล่องสีต่อมื้อ (เช้า/กลางวัน/เย็น/ของว่าง ใช้สี `.mk-*`) แต่ละกล่อง = ร้านแนะนำ (การ์ดขาว + ปุ่มนำทาง) · ร้านสำรอง · "กินมื้อนี้ได้อีก" (ร้านในคู่มือที่ระบุวัน/มื้อนั้น)
- ใต้มื้อ: "ร้านใกล้เส้นทางและที่พักวันนี้" เป็นกล่องพับตามย่าน (ย่านที่ระบุวันนั้น / ย่านของที่พักคืนนั้น / ย่านที่มีร้านในแผนวันนั้น)
- ปุ่มใหญ่ล่างสุด "ร้านทั้งหมด N ร้าน · ค้นหา" → `/eat/all` (การ์ดทุกร้าน + ค้นหา + ชิป เหมือนเดิม)
- จอกว้าง: กล่องสูงไม่เท่ากันต้องไม่เหลือช่องว่าง — หน้าวันนี้วัดความสูงกล่องจริงแล้วแบ่งสองคอลัมน์ให้ยาวใกล้กันที่สุด (`packBoxes()` ใน views.js — ทุกภาษา ทุกวัน, คำนวณใหม่เมื่อย่อ/ขยายจอ); กล่องมื้อในหน้าร้านอาหารเรียงแบบกำแพงอิฐ (`columns`)
- พาสปอร์ตบนจอกว้างใช้ `packBoxes()` เหมือนหน้าวันนี้ (สองคอลัมน์ตามความสูงจริง) · หัวข้อ/kicker ใช้ `text-wrap:balance` ไม่ให้เหลือคำเดียวบรรทัดสุดท้าย · ข้อความในตราประทับย่อตามคำที่ยาวที่สุด (ไม่ตัดกลางคำ ไม่ล้นวง) · ชื่อหมุดบนแผนที่อยู่ชั้นบนสุด ไม่ถูกตัวเด็กบัง
